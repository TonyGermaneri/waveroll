Clock traces captured from real hosts, replayed by `../replay.rs`.

Capture with `tools/clock-trace.html`. Name them `<host>-<tempo><what>.txt`, for example
`live12-128.txt` or `logic11-90-ramp.txt`, and keep the comment header the tool writes — it
records the host version and the date, which is the whole value of a trace once it is a year old.
